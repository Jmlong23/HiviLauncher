# Stream 音响 UI 产品 PRD

- 文档版本：V1.0
- 文档属性：UI/UX 设计说明 + 客户端开发需求
- 创建日期：2026-10-27
- 代码分支：`Stream`（HiviLauncher）
- 适用对象：UI 设计、交互设计、视觉设计、Android 客户端开发、测试
- 产品名称：Stream 智能音响（带屏）
- 本期范围：**首页** 与 **应用界面** 两个页面

> 本文档以"设计师可以直接据此画页面、开发可以直接据此排期"为目标。除特别说明外，所有状态（网络、音量、下载、安装）都必须在界面上给出清晰的视觉反馈。硬件参数以最终声学和结构评审为准。

## 1. 产品概述

Stream 是一款横屏带屏 Android 智能音响。相比 Soundbar 版本，Stream 的系统界面更轻量：不使用底部全局导航栏，首页直接承载"状态查看 + 应用直达 + 两个固定入口"，第三方在线音乐内容通过"应用"页下载安装后使用。

### 1.1 产品关键词

`轻量桌面`、`一屏直达`、`在线音乐内容`、`免商店安装`、`全局音量`、`简单易懂`。

### 1.2 目标用户

1. 家庭用户：开机即听，一屏找到想用的音乐服务。
2. 音乐用户：希望设备内置主流音乐/有声内容 App，无需自己找 APK、接显示器安装。
3. 长辈/儿童等新手用户：界面层级浅、按钮少、状态一眼可读。

### 1.3 核心设计目标

| 目标 | UI 设计要求 |
| --- | --- |
| 层级极浅 | 全部功能从首页一跳可达；应用页提供返回即可回到首页 |
| 状态一眼可读 | WiFi、音量在左上角常驻，不隐藏 |
| 内容开箱即用 | 未安装的音乐 App 也直接展示官方图标，点击即下载安装，不跳应用商店 |
| 图标真实可信 | 三方应用使用与官方一致的图标，降低辨识成本 |
| 触控友好 | 横屏远距离使用，热区 ≥ 48dp |

## 2. 全局设计约定

### 2.1 术语统一

| 术语 | 含义 |
| --- | --- |
| 首页 | 开机/按返回到根时的默认页面 |
| 应用界面 | 展示预置与已安装应用的页面（本期第二个页面） |
| 预置应用 | 设备未安装时也固定展示的三方音乐/音频应用，点击走"下载 → 静默安装 → 启动" |
| 下载角标 | 叠加在应用图标上的下载标识，表示该应用当前未安装 |

### 2.2 全局规则

- 屏幕为横屏，设计基准分辨率与安全边距以结构评审为准；内容区四周预留 ≥ 16dp 安全边距。
- 音量为全局功放音量，任何页面调节后全局生效，切页不重置。
- 页面背景使用深色（当前实现基色 `#363636`），文字主色 `#FFFFFF`，保证远距离可读。
- 所有可点击区域最小 48dp × 48dp；点击均需给出按压态反馈。

## 3. 信息架构

```text
首页
├── 左上角：WiFi 状态（点击 → WiFi 设置）
├── 左上角：音量按钮（点击 → 音量面板，全局浮层）
├── 中部：应用图标行（居中一行，直达三方音乐应用）
└── 应用行下方入口：
    ├── 系统设置（→ 设置页面，沿用现有设置模块）
    └── 应用（→ 应用界面）

应用界面
├── 左上角：返回（→ 回到首页）
├── 左上角：音量按钮（与首页同一音量面板）
└── 主内容：预置应用 + 已安装应用的网格
```

页面关系只有两级：首页 ↔ 应用界面。应用界面按返回回到首页；在应用界面内启动三方应用后，从三方应用返回应回到启动它的页面（首页图标行或应用界面）。

## 4. 首页

### 4.1 布局结构

```text
┌──────────────────────────────────────────────────────────────┐
│ (📶 WiFi状态)  (🔊 音量)                                       │
│                                                              │
│                                                              │
│            [QQ音乐] [网易云] [汽水] [酷狗] [酷我] [喜马拉雅]       │
│                 ⚙ 系统设置          ▦ 应用                     │
│                                                              │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

页面自上而下分为三个区域：

| 区域 | 位置 | 内容 | 高度建议 |
| --- | --- | --- | --- |
| 状态区 | 顶部左侧 | WiFi 状态 + 音量按钮 | 35–48dp |
| 应用图标行 | 垂直居中 | 预置音乐应用一行图标，整体水平居中 | 图标 54–64dp，含名称标签 |
| 入口区 | 应用图标行正下方，水平居中 | 系统设置、应用 两个入口 | ≥ 64dp |

### 4.2 左上角：WiFi 状态

- 位于屏幕左上角第一个位置，由"WiFi 图标（30dp）+ 状态文本（13sp，加粗）"组成一个整体可点击区域。
- 状态显示规则：

| 系统状态 | 图标 | 文本 |
| --- | --- | --- |
| 未连接任何 WiFi | 空信号 WiFi 图标（低对比度） | `未连接` |
| 正在连接 | WiFi 图标 + 闪烁动效 | `连接中…` |
| 已连接，信号弱 | 1 格 WiFi 图标 | 显示 SSID |
| 已连接，信号中 | 2 格 WiFi 图标 | 显示 SSID |
| 已连接，信号强 | 满格 WiFi 图标 | 显示 SSID |
| WiFi 总开关关闭 | 关闭态 WiFi 图标 | `未连接` |

- SSID 过长时中间截断（如 `HIVI-2.4G-…`），最多显示 12 个字符。
- 点击行为：进入设置中的 WiFi 管理页面（沿用现有 WiFi 模块），在 WiFi 页面内可再次返回首页。
- 状态变化（连接、断开、信号变化）实时刷新，无需手动刷新或重启。

### 4.3 左上角：音量按钮

- 紧跟 WiFi 状态右侧，间距 24dp，为独立音量图标按钮（30dp），点击热区 ≥ 48dp。
- 图标状态：

| 状态 | 图标 |
| --- | --- |
| 音量 > 0 | 喇叭 + 声波图标 |
| 音量 = 0 或静音 | 喇叭 + 斜杠/叉图标 |

- 点击行为：弹出全局音量面板浮层（复用现有 `dialog_volume` 交互），面板包含：
  - 音量滑杆（0–100）与当前数值（如 `32/100`）；
  - 静音切换按钮；
  - 调节过程中实时生效并出声反馈；
  - 点击面板外区域或 5 秒无操作自动关闭，关闭后音量值保持。
- 音量面板为全局浮层：在应用界面同样可通过左上角音量按钮唤起，交互完全一致。
- 长按音量按钮：直接切换静音/取消静音（可选增强项，见开放问题）。

### 4.4 中部：应用图标行

- 一行应用图标，整组水平、垂直居中，是首页的视觉主体。
- 展示内容：预置音乐应用固定顺序的前 N 个（建议 N=6，按第 5.3 节标准顺序取前 6 个：QQ音乐、网易云音乐、汽水音乐、酷狗音乐、酷我音乐、全民K歌）。
- 每个图标项：图标 54–64dp + 下方名称标签（16sp，加粗，白色，单行超长省略），与"应用"页网格项样式一致。
- 未安装的应用同样直接展示，图标上叠加下载角标（规则见 5.4 节），用户可从首页直接发起下载。
- 排列规则：
  - 等间距排列，图标间距 24–32dp；
  - 数量不足 N 个时不拉伸间距，保持固定间距居中；
  - 超出屏幕宽度时缩小间距优先保证一行放下；仍放不下则从末尾截断（完整列表在"应用"入口中查看）。
- 点击行为：与"应用"页一致——已安装直接启动；未安装走下载安装流程（见 5.5 节）。
- 应用安装状态变化（下载完成、卸载）实时刷新首页图标角标。

### 4.5 应用行下方：系统设置 / 应用

两个固定入口，位于应用图标行正下方（与图标行间距建议 32–48dp），水平居中排列，等宽等高，入口间距 32dp：

| 入口 | 图标 | 文本 | 点击行为 |
| --- | --- | --- | --- |
| 系统设置 | 齿轮 | `系统设置` | 打开设置页面（WiFi、蓝牙、语言、屏幕保护、系统更新、恢复出厂等，沿用现有设置模块，本期不在本 PRD 范围内） |
| 应用 | 四宫格 | `应用` | 进入应用界面 |

- 每个入口为"图标 + 文字"上下结构或左右结构（以视觉稿为准），整体热区 ≥ 120dp × 64dp。
- 入口风格与首页深色背景区分（卡片底或高亮描边，以视觉稿为准），保证是页面上第二视觉焦点（第一是图标行）。

│   [QQ音乐]  [网易云]  [汽水]  [酷狗]  [酷我]                     │

│                                                              │

- 顶部左侧依次为：返回按钮、音量按钮。
- 主内容为应用网格，从上到下、从左到右排列，整体在内容区内水平居中。

### 5.2 顶部：返回 + 音量

| 控件 | 位置 | 规格 | 行为 |

| 返回 | 左上角第一个 | "‹ 返回" 图标+文字，热区 ≥ 48dp | 返回首页；按返回键等效 |

- 未在上表中的已安装应用，本期不在应用界面展示（是否展示"全部已安装应用"见开放问题）。
- 列表固定顺序不随安装状态变化；未安装项保持原位，不做"已安装靠前"的动态排序（降低记忆成本）。

### 5.4 图标与下载角标规范

- **应用图标**：使用与三方官方一致的图标（视觉上与手机端用户认知一致），圆角矩形；量产前需完成官方图标授权或使用官方分发素材，开发期使用内置品牌风格占位图（现有 `ic_preset_*` 资源）。
- **下载角标（未安装态）**：
  - 叠加位置：图标右上角，直径约为图标的 1/3（约 18–20dp），压角 1/4 左右；
  - 角标样式：圆形底（高对比色，如品牌蓝或红色，以视觉稿为准）+ 白色向下下载箭头；
  - 同时图标本体不透明度降至约 50%，与已安装应用形成明确区分；
  - 已安装后角标立即消失，图标恢复 100% 不透明度。
- **下载中态**：角标位置替换为环形进度（或百分比文字，以视觉稿为准），进度实时刷新；下载与安装期间图标保持半透明。
- **安装完成**：角标消失 → 自动启动该应用。
- 命名标签：图标下方显示应用官方名称（16sp，加粗，白色，单行省略）。

### 5.5 点击行为与下载安装流程

**已安装应用**：点击 → 直接启动该应用。

**未安装（预置）应用**：点击 → 走"下载 APK → 静默安装 → 自动启动"流程，全程不离开当前界面、不跳转应用商店：

| 阶段 | 界面反馈 | 异常处理 |
| --- | --- | --- |
| 点击发起 | 角标进入下载中态；Toast 提示"开始下载 xxx" | 无网络：Toast 提示"网络未连接，请先连接 WiFi"，不发起下载 |
| 下载中 | 角标环形进度实时刷新 | 下载失败/中断：Toast 提示"下载失败，请重试"，角标恢复为下载角标，可再次点击重试 |
| 下载完成 → 安装 | 角标显示"安装中"态 | 安装失败：Toast 提示"安装失败，请重试"；存储不足单独提示"存储空间不足" |
| 安装成功 | 角标消失，列表项变为已安装态 | — |
| 自动启动 | 安装成功后 1 秒内自动启动该应用 | — |

- 下载期间允许用户继续操作其他应用（不阻塞界面）；同一应用重复点击不重复发起下载。
- 支持多应用并行下载（若性能允许，至少保证串行队列不丢任务，断电重启后未完成项恢复为未安装态）。
- APK 下载地址由服务端文件服务器提供（当前实现中 `DOWNLOAD_BASE_URL` 待运维部署后配置；为空时点击提示"暂未提供下载"）。
- 静默安装依赖系统签名权限，无需用户在弹窗中确认。

## 6. 状态与异常场景汇总

| 场景 | 表现 |
| --- | --- |
| WiFi 断开 | 首页左上角状态实时变为"未连接"；发起下载时给予无网络提示 |
| 音量为 0 | WiFi 旁音量按钮显示静音图标；音量面板滑杆位于 0 |
| 预置应用未安装 | 图标 + 下载角标 + 半透明，点击可发起下载 |
| 预置应用下载中 | 角标显示进度，防重复点击 |
| 预置应用安装完成 | 角标消失，自动启动 |
| 用户卸载预置应用 | 对应项恢复"下载角标"未安装态，回到可下载列表 |
| 应用页无任何已安装应用 | 全部显示为未安装态预置应用（正常态，不显示空页面） |
| 长按应用 | 本期无长按操作（卸载走系统设置或后续版本） |
